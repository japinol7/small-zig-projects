### Installing Zig
* URL:  https://ziglang.org/download/
  * Ex. file name:  zig-x86_64-linux-0.17.0.tar.xz
  * Verifying Signature for downloaded file
    * minisign -Vm FILE -P PUBLIC_KEY
    * You can install minisign with
      * sudo apt install minisign
    * Docs:
      * URL:  https://jedisct1.github.io/minisign/
      * URL:  https://github.com/jedisct1/minisign
